How to Use

Three powerful actions, one simple workflow.

  1. Click into any text field on a supported website
  2. Type your text (or select a portion of it)
  3. Press the shortcut for the action you want
  4. Review the result, edit if needed, then click Use This
🎯
Optimize Prompt

Transforms rough ideas into well-structured AI prompts. Adds clarity, context, and formatting to get better responses from Claude, ChatGPT, Gemini, or any AI.

✉️
Formalize Message

Rewrites casual text into professional, polished language. Perfect for emails, Slack messages, or any business communication.

✨
Generate Text
{ your instruction }

Wrap any instruction in curly braces and trigger either shortcut. The entire command gets replaced with generated content.

Example {write me an email to my manager letting them know I won't be in tomorrow}
💡
Selection mode — Select a portion of text before pressing the shortcut and only the selected part will be processed. The surrounding text stays untouched.
